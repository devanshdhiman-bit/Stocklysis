# 📊 StockLysis — Market Insights, Simplified

StockLysis is a multi-page stock market education and insights web platform built with pure HTML, CSS, and JavaScript. Designed for beginners and curious learners, it brings together live-style market data, news, watchlists, and guided learning — all in one place.

---

## 🚀 Features

- 📊 **Dashboard** — Browse 50+ stocks with color-coded price movements and sector filters
- ⭐ **Watchlist** — Save your favorite stocks with auto-generated Buy / Hold / Sell recommendations
- 📰 **News Feed** — Curated financial news with community like/dislike reactions
- 🔍 **Stock Comparison** — Compare any two stocks side-by-side across key metrics
- 💡 **Beginner Tips** — Guided investment concepts for first-time learners
- ❓ **Community Q&A** — Submit, search, and export stock market questions
- 🌙 **Dark / Light Mode** — Full theme toggle powered by CSS variables
- 📤 **Export to Excel** — Download Q&A data as `.xlsx` using SheetJS

---

## 🛠 Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Semantic page structure across 9 pages |
| CSS3 | Custom variables, Flexbox, responsive layout, dark/light themes |
| JavaScript (ES6+) | DOM manipulation, localStorage, dynamic rendering |
| Chart.js | Stock price and movement charts |
| SheetJS (xlsx) | Export Q&A list to downloadable Excel file |
| localStorage | Client-side persistence for watchlists and Q&A |
